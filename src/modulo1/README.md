# Módulo 1 — Fundamentos do Java

Este módulo reúne os primeiros conteúdos estudados no aprendizado de **Java**, com foco nos conceitos fundamentais da linguagem e nas primeiras estruturas utilizadas para desenvolver programas.

## 📚 Conteúdos

### Fundamentos

Nesta parte são abordados conceitos básicos da linguagem Java, como:

* Variáveis
* Tipos de dados
* Operadores
* Entrada e saída de dados
* `Scanner`
* `var`
* Concatenação
* Formatação de textos
* Conversão de tipos (`casting`)

### Estrutura de Controle

Nesta parte são estudadas as estruturas utilizadas para controlar o fluxo de execução dos programas:

* `if`
* `else`
* `else if`
* Operadores relacionais
* Operadores lógicos
* Estruturas condicionais
* `switch`
* Estruturas de repetição
* `for`
* `while`
* `do while`

## 🎯 Objetivo

O objetivo deste módulo é construir uma base sólida nos conceitos fundamentais do Java, permitindo desenvolver programas simples e compreender melhor as estruturas utilizadas na linguagem.
